# 2026-10-25

## 金币经济系统（雏形）

需求：击杀僵尸有概率掉金币，用途暂定。

### 实现
- **`scripts/units/coin_orb.gd`（新）**：CoinOrb 复用 SunOrb 的磁吸取物模式，多了抛出弧线 +
  两次落地弹跳 + 立式旋转 + 24s 生命（最后 3s 闪烁）。`Art.coin_model()` 是币身 +
  两面压纹圈 + 中心亮斑 + 反向自转的十字光斑。
- **掉落表** `Data.COIN_TABLE`：普通 32%/1 → 巨人 100%/5（橄榄球 65%/2、舞王 60%/2、
  铁桶/铁门 50%、伴舞仅 25%）。`Match._drop_coins(z)` 挂在 `z.died` 上——被小推车辗、
  魅惑倒戈、核爆炸死的都掉钱。
- **收集**：2.1m 磁吸（`_update_coins` 跟在 `_update_suns` 后）+ `E` 准星直收
  （`collect_nearby` 无阳光时落到 `_collect_coin_in_view`）。
- **钱袋**：`App.save["coins"]` + `wallet()/add_coins()`；对局结束（won/lost/无尽）
  在 `_on_state` 一次性入账。HUD `CoinBadge`（阳光面板下方）、菜单 `CoinPurse`（右上角）、
  结算页「金币 +N」三处显示。
- **音频**：`coin.wav` 两音叮（1318→1760 Hz），gen_audio.py 合成。

### 验证（--test=coins 全绿）
- 巨人必掉 5；120 只普通掉 35 枚（32% 期望 38，落在 26–52 区间）
- 磁吸收集、`bank 0+N -> N ok=true`、存档回读恢复、HUD 徽章存在
- 回归：boot 无错、plants/zombies/flow 全绿、front-1 sim 仍 won（15 杀，coins=0 正确——
  sim 里玩家不动，掉的币没人捡，符合"必须走过去收"的设计）
- 截图：`--shot=coins`（草坪金币 + 徽章 1287）、菜单钱袋 1284、结算「金币 +342」

### 设计取舍（已写进 README）
- 金币只累计不能花，商店接口留 `App.wallet()/add_coins()`，用途待定。
- 场上金币不自动入账，必须走近收——保留"打完绕一圈捡钱"的节奏。
- headless 退出仍有 4 个音频实例泄漏（AudioStreamWAV/MP3 及其 playback）——
  是 dummy 音频驱动的老问题，带窗口跑不报，与金币无关。
