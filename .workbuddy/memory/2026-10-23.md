# 2026-10-23

## 把 PVZ3D 页游重做成 Godot 4.7 项目

产出：`D:/PVZ3D/godot/`（完整可运行），原 Three.js 版保持在仓库根目录不动。

**关键决定**
- 全部场景用代码构建（只有一个 `scenes/main.tscn` 挂 `main.gd`），避免手写 .tscn 出错。
- 美术零外部资源：`scripts/art.gd` 拼低多边形模型，`shaders/toon.gdshader` 做分级光照 + `next_pass` 法线外扩描边。
- 音频用 `tools/gen_audio.py`（纯 Python 标准库）合成 23 个 wav 到 `godot/audio/`。
- 中文 UI 必须自带字体：复制了 `C:/Windows/Fonts/Noto Sans SC*.otf` 到 `godot/fonts/`，否则默认字体没有 CJK 字形。
- 输入映射在 `App._setup_input()` 里用 `InputMap.add_action` 运行时注册，不写进 project.godot。

**踩过的坑（下次直接避开）**
- Godot 4 的 `Control` 用 `set_anchors_preset()` 之后再赋 `position`，锚点会失效；HUD 布局全部改成绝对坐标 + `get_viewport().get_visible_rect()`。
- `PanelContainer`/`VBoxContainer` 会按最小尺寸压扁自己，手写 UI 用 `Panel` + 手动定位最省事。
- `AnimatableBody3D.sync_to_physics = true` 时 `global_position` 读回是滞后的，快进模拟里僵尸不动。改成 false + 本地 `body_x` 变量。
- 自定义 spatial shader 里写 `light()` 要自己加 `/ PI`，并靠 `ATTENUATION` 拿阴影。
- 草坪/地面如果整片盖住泳池，水面永远看不见：地面要拆成绕开泳池的四块。
- 后院列坐标必须按 `house_side` 翻转（col 0 = 靠近房子的那列），否则植物种到了僵尸出生端、子弹永远不发射。
- 覆盖全屏的半透明白雾，元凶是网格 shader 用了 UV 导致 alpha 恒为 1；改成世界坐标算格子后正常。

**验证方式**
- `--headless -- --sim=230 --level=X --plants="c,r,kind;..."` 无渲染跑完整关，打印 `state/kills/mowers_used`。四关都已验证可通、无植物会输。
- `--shot=menu|play|pause|end --cam=x,y,z,yaw,pitch --out=xx.png` 截图验收。截图后 `OS.kill` 兜底退出（D3D12 关闭偶发卡住）。

## 补二：后门通泳池 + 烟囱上屋顶（同日）

用户反馈"地图不完整，要房子有后门连接后院泳池；二楼加烟囱，能爬屋顶"。

### 做了什么
- **后门**：西墙在 `z=3.35` 开了 1.12×2.08 的洞（墙拆成左右+过梁三段），装了带门框的真铰链门
  （`HouseDoor`，向内开）。同时删掉 `_deck()` 里那块假门板，并砍掉与该位置重叠的一层后墙窗户
  （`floor_i==0 and i==count-1` 跳过）。
- **露台→后院的路**：原来 `_fences()` 在 `x=-19.9` 拉了一整条栅栏，把露台和泳池隔死；
  现在拆成两段，中间留 `z 2.72..3.98` 的门洞，装了一扇**可开关的栅栏门**（`_make_door(..., style="gate")`
  + 两根门柱 + 小拱架 + 夜间灯笼）。露台加了躺椅（带坐垫）、边几、两级下台阶（视觉踏步 +
  一整块斜面碰撞体）、踏石步道。
- **烟囱**：二楼北墙 `x -14.0..-12.2 / z -6.22..-4.72`，空心三段砖壁，从楼板直通 `y=10.05`；
  南面是 1.2×2.1 的炉膛（可走进去），柴火 + 碳火 + 跳动 OmniLight + 从烟囱口打下来的 SpotLight。
  二层天花板和屋顶都在烟囱位置断开重铺（`_roof_band(side, gap, z0, z1)` 按 z 分三段，中间那段
  离屋脊留 0.92m）。
- **爬烟囱**：`WorldBuilder.chimney_look()` 判定准星（屋内 eye.y<6 / 屋顶 eye.y>7.4），
  `chimney_path()` 给折线，`PlayerController.climb_to(path, dur)` 按弧长匀速补间，期间
  `climbing=true` 跳过物理、隐藏手部模型。落点 `(-13.1, 8.59, -4.28)` 站在屋脊上。
- 屋顶加了碰撞（`_roof_band` 里 `_collide`），两坡都能走。

### 挖出来的真 bug
- **`toon.gdshader` 里写了 `ALPHA`** → Godot 把整个材质丢进透明队列 → 透明材质不写深度 →
  站在屋外能直接看见屋里的楼梯、沙发（后墙等于没有）。拆成 `toon.gdshader`（不写 ALPHA）
  + `toon_alpha.gdshader`（`blend_mix, depth_draw_never`，给种植预览/爆炸/尘土用），
  `Art.toon()` 按 `alpha<1` 选着色器。这一修全场景立体感都对了。
- `Art.toon()` 的材质缓存 key 漏了 `outline`，顺手补上。
- 露台的台阶正对着泳池东岸（原来 `_deck` 的楼梯落在水里），已改到南侧并加门。
- `Vector3(x, y)` 两参构造在 4.7 会编译失败（`_pool` 旁边那组踏石）。

### 验证
- `--walk=backyard`：客厅 (-16.9) → 穿后门 → 下台阶 → 穿栅栏门 → 草坪 (-27.9)，y 0.45→-0.02。
- `--walk=gateclosed`：被挡在 x=-19.52。
- `--walk=chimney`：从二楼 y=3.45 爬到 y=8.586，`on_floor=true`。
- `--sim=230` 仍能通关；`--walk=stair/door/doorclosed` 全部照旧。
