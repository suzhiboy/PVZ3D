# 视觉方向：手绘微缩庭院

## 目标风格

保留现有的低多边形轮廓、暖绿色调和墨线描边，但把“平涂纸片模型”升级成
**带手绘颜料层次和微缩模型光影的立体庭院**。

一句话判断标准：远看仍是熟悉的《植物大战僵尸》庭院，近看有材质、空气和光。

不做写实化，不换模型资产，不改变角色比例和玩法识别点。

**后续角色精修例外**：植物与场景继续沿用手绘低多边形体系；僵尸单独升级为高精度
平滑曲面，不使用低模描边。其材质仍遵循“暖阳冷影”和微弱颜料噪声，因此属于同一世界，
只是角色的细节层级更高。

## 四条统一原则

1. **轮廓优先**：植物和僵尸的辨识度来自外轮廓，所有新增细节不得破坏剪影。
2. **暖阳冷影**：直射光偏奶油金，背光与天光偏蓝绿；阴影有颜色，不压成黑色。
3. **颜料感而非塑料感**：表面允许轻微色差和笔触噪声，但不使用写实照片纹理。
4. **植物志式 UI**：深苔绿底板、黄铜细边、奶油色文字，像庭院里的植物标牌，
   不使用高饱和霓虹色和纯黑面板。

## 具体落地

### 1. 全局角色与道具材质

文件：`shaders/toon.gdshader`、`shaders/toon_alpha.gdshader`、`scripts/art.gd`

- 三段硬色阶改成“色阶 + 平滑过渡”的混合光照（保留 32% 平滑量）。
- 世界空间加入极低强度的双层颜料噪声，避免大面积纯色发塑料。
- 受光面加入暖色偏移，暗面加入冷色偏移；高光增加很弱的宽反射。
- 统一粗糙度参数，金属件可单独提高 `gloss`（水桶、推车等）。
- 描边由纯黑改成暖炭黑，并稍微收细，减少“贴纸边”。
- 缓存键加入材质参数，保持每次生成同一个材质的结果一致。

### 2. 环境与光影

文件：`scripts/world.gd`

- ACES 色调映射、曝光重新标定，降低天空过曝。
- SSAO 半径/强度提升，接触阴影更扎实。
- 太阳阴影变软，填充光偏蓝，形成暖冷对比。
- 雾颜色按清晨/午后/泳池/深夜分别调色，并用 aerial perspective 拉开远景。
- 统一调色：略降饱和、提高对比，避免荧光绿；夜间单独提高曝光保留可读性。

### 3. 草坪、树木与花境

文件：`shaders/grass.gdshader`、`scripts/world.gd`

- 草坪增加大尺度苔绿斑块、中尺度干草斑和细小亮尖；割草纹由硬边改成柔和过渡。
- 保留很弱的种植格明暗，不牺牲瞄准可读性。
- 树冠由 5 个大球改成 7 个不规则叶团 + 阳光顶层 + 三团侧叶，增加体积层次。
- 灌木改成 5 个不等距叶团，避免“一串葡萄”的重复感。
- 花境由单个色块花头改成五瓣花与金色花心，丰富前景细节。

### 4. 水面

文件：`shaders/water.gdshader`、`scripts/world.gd`

- 水面细分从 12×4 提升到 28×8，法线由真实波高推导。
- 两组交叉波 + 一组细波，保留水面起伏。
- 用菲涅尔混合深浅水色，压低镜面高光，避免大块白色塑料反光。
- 池边加入低强度矿物白边，水花仍由 `water_fx.gd` 提供。

### 5. HUD 与菜单

文件：`scripts/app.gd`、`scripts/hud.gd`、`scripts/ui/menu.gd`、`scripts/ui/seed_chooser.gd`

- 面板改为深苔绿半透明底 + 黄铜细边 + 柔和投影。
- 圆角统一为 12–24 px 层级；按钮增加悬停金色描边。
- 阳光面板加入光环、细金线；波次条加入金色进度端点。
- 种子卡、关卡卡、选卡卡使用同一套底色、边框和字色。
- 只在 3D 画面上加一层很轻的分割调色、暗角和纸纹；HUD 不受这层影响。

## 预期呈现

- 白天：远景有轻微空气透视，草坪是深浅不一的苔绿而不是整块荧光绿，植物边缘有暖色轮廓。
- 黄昏/夜晚：冷色环境光保留细节，金色灯光和 UI 形成统一的暖点。
- 水面：能看到连续的细波、柔和反射和池边泡沫，不再出现大块白斑。
- UI：与庭院像同一套“植物标牌”，不抢角色，也不会变成通用游戏 HUD。
- 性能：仍是单 Pass 卡通材质和程序化几何，没有引入外部贴图或后处理链；
  主要新增开销来自 SSAO、全屏调色和树冠细分，桌面端优先。
